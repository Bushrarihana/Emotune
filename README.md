# EmoTune 🎵😊

EmoTune is an emotion detection music recommendation system based on facial emotion, voice and weather

## Features
- Face emotion detection
- Voice emotion detection
- Weather-based mood detection
- Spotify playlist recommendation
- Real-time webcam emotion analysis

## Technologies Used
- Python
- Flask
- TensorFlow
- OpenCV
- Keras
- Librosa
- Spotify

## Installation

```bash
pip install -r requirements.txt
```

## Run Project

```bash
python app.py
```
